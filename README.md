# Poke-Go

App hecha con Expo y expo-router que muestra una lista de Pokémon usando la PokeAPI.

## Qué hace

- Trae los primeros 20 Pokémon de la API y luego pide los detalles de cada uno.
- Muestra sus imágenes y les pone color según su tipo.
- Al tocar un Pokémon abre una pantalla con sus detalles (altura, peso, habilidades y estadísticas).

## Cómo correrlo

npm install
npx expo start

Luego escanea el QR con Expo Go o presiona `w` para abrirlo en el navegador.
